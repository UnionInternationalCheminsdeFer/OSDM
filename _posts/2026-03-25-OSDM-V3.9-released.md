We are proud to release **Version 3.9** of the
[OSDM Specification](https://osdm.io/spec/). This increment brings a range of
improvements contributed by the different parties. This release does not include any changes on the 
messages but restructures the API schema files in a more modular way.



More to come!

Thanks to all the [Team](https://osdm.io/team/) for its hard work.
