We are proud to release **Version 3.10** of the
[OSDM Specification](https://osdm.io/spec/). This increment brings a range of
improvements contributed by the different parties. Highlights of this release
include:

- **externalizing FulfillmentDocument** — included docments have been replaced by refferences
- **ID photo in passenger description** — passenger description might include a photo is required
- **Alternative system proposal**  — proposal for alternative systems to call added in problem structure
- **Querry a list of vehicle layouts**  — query parameters added to reuest  list of vehicle layouts

See the
[Release Notes 3.10](https://osdm.io/releases/OSDM-release-notes-v3.10/)
for the full list of changes.

More to come!

Thanks to all the [Team](https://osdm.io/team/) for its hard work.
